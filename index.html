texto_grafica <- function(x) {
  if (is.null(x)) {
    return(NULL)
  }
  y <- iconv(as.character(x), from = "UTF-8", to = "ASCII//TRANSLIT", sub = "")
  ifelse(is.na(y), as.character(x), y)
}

grafica_normal <- function(media, desviacion, inferior = -Inf, superior = Inf,
                           color = "steelblue", titulo = "Distribucion Normal",
                           subtitulo = NULL, eje_x = "x") {
  limites <- c(inferior, superior)
  finitos <- limites[is.finite(limites)]
  rango <- range(c(media - 4 * desviacion, media + 4 * desviacion, finitos))
  x <- seq(rango[1], rango[2], length.out = 900)
  datos <- data.frame(x = x, y = dnorm(x, mean = media, sd = desviacion))
  sombra <- subset(datos, x >= inferior & x <= superior)

  ggplot(datos, aes(x, y)) +
    geom_line(color = "black", size = 0.9) +
    geom_area(data = sombra, aes(x, y), fill = color, alpha = 0.55) +
    geom_vline(
      xintercept = c(inferior, superior)[is.finite(c(inferior, superior))],
      linetype = "dashed",
      color = "red"
    ) +
    labs(
      title = texto_grafica(titulo),
      subtitle = texto_grafica(subtitulo),
      x = texto_grafica(eje_x),
      y = "Densidad de probabilidad"
    ) +
    coord_cartesian(xlim = rango, ylim = c(0, max(datos$y) * 1.08), expand = TRUE) +
    theme_minimal(base_size = 13)
}

2 Distribución Normal

La distribución normal, también conocida como distribución gaussiana o campana de Gauss, es la distribución de probabilidad continua más importante en la estadística. Su importancia radica en que muchos fenómenos naturales, sociales y económicos siguen este patrón.

La distribución normal es una herramienta fundamental para modelar una inmensa variedad de fenómenos en las ciencias, la ingeniería y la economía. Su popularidad se debe a una propiedad matemática conocida como el Teorema del Límite Central, que establece que la suma o el promedio de un gran número de variables aleatorias independientes, sin importar su distribución original, tiende a seguir una distribución normal.

Características clave

La distribución normal es un tipo de distribución de probabilidad continua. Esto significa que la variable aleatoria puede tomar cualquier valor dentro de un rango determinado. Se representa por una curva simétrica en forma de campana, donde la mayor parte de los datos se agrupan alrededor del valor central.

Forma de campana: la distribución es simétrica alrededor de su media. El punto más alto de la campana corresponde a la media.

Media, mediana y moda coincidentes: en una distribución normal perfecta, estos tres valores son iguales y se encuentran en el centro de la curva.

Asintótica al eje horizontal: la curva se extiende indefinidamente en ambas direcciones, acercándose al eje x pero sin llegar a tocarlo.

Regla empírica: alrededor del 68% de los datos se encuentran dentro de una desviación estándar de la media \((\mu \pm \sigma)\), el 95% dentro de dos desviaciones estándar \((\mu \pm 2\sigma)\) y el 99.7% dentro de tres desviaciones estándar \((\mu \pm 3\sigma)\).

Parámetros

La distribución normal está completamente definida por dos parámetros:

Media \((\mu)\): indica la ubicación del centro de la curva y el valor más probable.

Varianza \((\sigma^2)\) o desviación estándar \((\sigma)\): mide la dispersión o variabilidad de los datos. Una desviación estándar grande produce una curva más ancha y aplanada, mientras que una desviación estándar pequeña produce una curva más estrecha y alta.

Fórmulas

La fórmula principal de la distribución normal es la función de densidad de probabilidad. Esta función no calcula la probabilidad de un punto exacto, sino la densidad de probabilidad en ese punto.

La función de densidad de una variable normal es:

\[ f(x)=\frac{1}{\sigma \sqrt{2\pi}} e^{-\frac{1}{2}\left(\frac{x-\mu}{\sigma}\right)^2} \]

Donde \(x\) es el valor de la variable aleatoria, \(\mu\) es la media, \(\sigma\) es la desviación estándar, \(e\) es el número de Euler y \(\pi\) es la constante pi.

La estandarización se realiza con:

\[ Z=\frac{x-\mu}{\sigma} \]

La puntuación \(Z\) indica cuántas desviaciones estándar está un valor dado respecto a la media. Luego se usan tablas o software estadístico para encontrar las probabilidades correspondientes.

3 Distribución Ji Cuadrado

La distribución ji-cuadrado \(\chi^2\) es una distribución de probabilidad continua definida para valores no negativos. Surge de la suma de los cuadrados de variables normales estándar independientes y depende de un parámetro llamado grados de libertad. Su media es igual a los grados de libertad, su varianza es el doble de los grados de libertad y su forma varía según dicho parámetro: es muy asimétrica para valores pequeños y se aproxima a una normal al crecer.

Esta distribución es fundamental en estadística porque se utiliza en pruebas de hipótesis, como bondad de ajuste e independencia en tablas de contingencia, en la construcción de intervalos de confianza para varianzas y en la base de otras distribuciones como la t de Student y la F de Fisher. En términos intuitivos, mide la dispersión total al sumar cuadrados de desviaciones de normales, por lo que resulta clave para analizar varianzas y asociaciones entre variables.

Parámetros y características

A diferencia de la distribución normal, la distribución ji-cuadrado no está definida por una media y una desviación estándar, sino por un único parámetro:

Grados de libertad \((v)\): determina la forma de la distribución. A medida que los grados de libertad aumentan, la forma se vuelve más simétrica y se aproxima a una distribución normal.

Valores no negativos: la variable ji-cuadrado solo puede tomar valores positivos, ya que se calcula a partir de una suma de cuadrados. Por lo tanto, su curva comienza en cero y se extiende hacia la derecha.

Asimétrica a la derecha: presenta una cola larga hacia la derecha, especialmente con pocos grados de libertad.

Media y varianza: la media de la distribución es \(\mu = v\) y la varianza es \(\sigma^2 = 2v\).

Dominio: \(X \ge 0\).

Usos principales en estadística

La distribución \(\chi^2\) es fundamental en estadística inferencial. Se usa en pruebas de bondad de ajuste para verificar si los datos observados se ajustan a una distribución teórica, en pruebas de independencia para evaluar si dos variables categóricas son independientes y en intervalos de confianza para la varianza poblacional cuando la población es normal.

La función de densidad puede escribirse como:

\[ f(x;k)=\frac{1}{2^{k/2}\Gamma(k/2)}x^{k/2-1}e^{-x/2}, \quad x>0 \]

Aquí \(\Gamma(\cdot)\) representa la función gamma y \(k\) es el número de grados de libertad.

4 Distribución T de Student

La distribución t de Student es una distribución de probabilidad continua que surge al estimar la media de una población normalmente distribuida cuando el tamaño de la muestra es pequeño y la varianza poblacional es desconocida. Fue introducida en 1908 por William Sealy Gosset bajo el seudónimo de Student.

Su forma es simétrica respecto al cero, similar a la normal estándar, pero con colas más pesadas; por esta razón asigna mayor probabilidad a valores extremos. Depende de los grados de libertad: a mayor número de grados de libertad, la distribución se aproxima cada vez más a la normal estándar \(N(0,1)\).

Principales características

Forma: es simétrica respecto al cero y tiene forma de campana.

Parámetro: depende de los grados de libertad \(v\).

Media: es 0 para \(v > 1\).

Varianza: es \(\frac{v}{v-2}\) para \(v > 2\).

Usos principales

Se usa en pruebas de hipótesis sobre medias, en la construcción de intervalos de confianza para la media y para modelar incertidumbre en muestras pequeñas cuando la desviación estándar poblacional no se conoce.

Si \(Z \sim N(0,1)\) y \(V \sim \chi^2_v\) son independientes, entonces:

\[ T=\frac{Z}{\sqrt{V/v}} \]

sigue una distribución t de Student con \(v\) grados de libertad.

Su función de densidad es:

\[ f(t)= \frac{\Gamma\left(\frac{v+1}{2}\right)} {\sqrt{v\pi}\,\Gamma\left(\frac{v}{2}\right)} \left(1+\frac{t^2}{v}\right)^{-\frac{v+1}{2}}, \quad -\infty<t<\infty \]

5 Distribución F de Fisher

La distribución F, también conocida como F de Fisher-Snedecor, es una distribución de probabilidad continua que surge a partir de la razón entre dos variables aleatorias chi-cuadrado normalizadas por sus grados de libertad.

La distribución F solo toma valores positivos, es asimétrica a la derecha y se concentra cerca de 1 cuando los grados de libertad son grandes. Es especialmente importante en el análisis de varianza, en pruebas de hipótesis sobre varianzas y en regresión lineal, donde la prueba F permite evaluar la significancia global de un modelo.

Propiedades principales

Soporte: \(F > 0\).

Asimetría: la curva de densidad es sesgada a la derecha, especialmente con pocos grados de libertad.

Esperanza matemática: \(E(F)=\frac{v_2}{v_2-2}\) para \(v_2 > 2\).

Varianza: \(\operatorname{Var}(F)=\frac{2v_2^2(v_1+v_2-2)}{v_1(v_2-2)^2(v_2-4)}\) para \(v_2 > 4\).

Usos más comunes

Se utiliza en análisis de varianza para contrastar si varias medias poblacionales son iguales, en pruebas para comparar varianzas de dos poblaciones y en modelos de regresión lineal para evaluar la significancia global.

Si \(X \sim \chi^2_{v_1}\) y \(Y \sim \chi^2_{v_2}\) son independientes:

\[ F=\frac{X/v_1}{Y/v_2} \]

Una forma de escribir su función de densidad es:

\[ f(x;v_1,v_2)= \frac{\Gamma\left(\frac{v_1+v_2}{2}\right)} {\Gamma\left(\frac{v_1}{2}\right)\Gamma\left(\frac{v_2}{2}\right)} \left(\frac{v_1}{v_2}\right)^{v_1/2} x^{v_1/2-1} \left(1+\frac{v_1}{v_2}x\right)^{-\frac{v_1+v_2}{2}}, \quad x>0 \]

6 Teorema del Límite Central

El Teorema del Límite Central (TLC) es uno de los conceptos más importantes en estadística. En términos simples, establece que la distribución de la media de una muestra se aproxima a una distribución normal a medida que el tamaño de la muestra aumenta, sin importar la forma de la distribución original de la población.

Concepto y analogía

Imagina que tienes una población con una distribución extraña, por ejemplo muy sesgada. Si tomas una sola muestra grande de esa población y calculas su media, esa media se comportará de manera más predecible. Si repites este proceso muchas veces, las medias de todas esas muestras formarán un histograma que se parecerá cada vez más a una curva de campana, es decir, a una distribución normal.

Una analogía popular es la de los dados. La distribución de probabilidad de un solo dado es uniforme, porque cada número tiene la misma probabilidad. Sin embargo, si lanzas muchos dados y sumas sus resultados, la distribución de esas sumas se aproxima a una campana, con los resultados centrales siendo mucho más probables que los extremos.

Puntos clave del teorema

  1. Forma de la distribución de muestreo: la distribución de las medias de la muestra se vuelve aproximadamente normal, aunque la población original sea normal, sesgada, uniforme o tenga otra forma.

  2. Tamaño de la muestra: la aproximación a la normalidad es más precisa a medida que el tamaño de la muestra aumenta. Generalmente, una muestra de \(n \ge 30\) se considera suficiente para que la aproximación sea razonable.

  3. Relación con la media de la población: la media de la distribución de muestreo de las medias es igual a la media de la población.

  4. Relación con la desviación estándar de la población: la desviación estándar de la distribución de muestreo de las medias, llamada error estándar, es igual a la desviación estándar de la población dividida por la raíz cuadrada del tamaño de la muestra.

Importancia

El Teorema del Límite Central permite utilizar la distribución normal para hacer inferencias sobre la media de la población, incluso cuando no se conoce la distribución de la población original. Esto es la base para muchas pruebas estadísticas, intervalos de confianza y procedimientos de inferencia.

Si la población tiene media \(\mu\) y desviación estándar \(\sigma\), entonces la media muestral cumple aproximadamente:

\[ \mu_{\bar{x}}=\mu, \qquad \sigma_{\bar{x}}=\frac{\sigma}{\sqrt{n}} \]

Por tanto, cuando \(n\) es suficientemente grande:

\[ Z=\frac{\bar{X}-\mu}{\sigma/\sqrt{n}}\approx N(0,1) \]

datos_distribucion_app <- reactive({
  modelo <- valor_app(input$modelo_app, "normal")
  req(modelo != "tlc")

  set.seed(semilla_app())
  n_sim <- as.integer(valor_app(input$n_sim_app, 3000))
  tipo <- valor_app(input$tipo_region_app, "izquierda")

  if (modelo == "normal") {
    mu <- valor_app(input$mu_app, 0)
    sigma <- max(valor_app(input$sigma_app, 1), 0.01)
    muestra <- rnorm(n_sim, mean = mu, sd = sigma)
    x <- seq(qnorm(0.001, mu, sigma), qnorm(0.999, mu, sigma), length.out = 900)
    y <- dnorm(x, mean = mu, sd = sigma)
    acumulada <- function(z) pnorm(z, mean = mu, sd = sigma)
    media_teo <- mu
    sd_teo <- sigma
    nombre <- "Normal"
    parametros <- paste("mu =", round(mu, 4), "| sigma =", round(sigma, 4))
  } else if (modelo == "chi") {
    gl <- max(1, round(valor_app(input$gl_chi_app, 5)))
    muestra <- rchisq(n_sim, df = gl)
    x <- seq(0, qchisq(0.999, df = gl), length.out = 900)
    y <- dchisq(x, df = gl)
    acumulada <- function(z) pchisq(z, df = gl)
    media_teo <- gl
    sd_teo <- sqrt(2 * gl)
    nombre <- "Ji-cuadrado"
    parametros <- paste("gl =", gl)
  } else if (modelo == "t") {
    gl <- max(1, round(valor_app(input$gl_t_app, 10)))
    muestra <- rt(n_sim, df = gl)
    x <- seq(qt(0.001, df = gl), qt(0.999, df = gl), length.out = 900)
    y <- dt(x, df = gl)
    acumulada <- function(z) pt(z, df = gl)
    media_teo <- if (gl > 1) 0 else NA_real_
    sd_teo <- if (gl > 2) sqrt(gl / (gl - 2)) else NA_real_
    nombre <- "t de Student"
    parametros <- paste("gl =", gl)
  } else {
    gl1 <- max(1, round(valor_app(input$gl1_f_app, 5)))
    gl2 <- max(1, round(valor_app(input$gl2_f_app, 10)))
    muestra <- rf(n_sim, df1 = gl1, df2 = gl2)
    x <- seq(0, qf(0.995, df1 = gl1, df2 = gl2), length.out = 900)
    y <- df(x, df1 = gl1, df2 = gl2)
    acumulada <- function(z) pf(z, df1 = gl1, df2 = gl2)
    media_teo <- if (gl2 > 2) gl2 / (gl2 - 2) else NA_real_
    sd_teo <- if (gl2 > 4) {
      sqrt((2 * gl2^2 * (gl1 + gl2 - 2)) / (gl1 * (gl2 - 2)^2 * (gl2 - 4)))
    } else {
      NA_real_
    }
    nombre <- "F de Fisher"
    parametros <- paste("gl1 =", gl1, "| gl2 =", gl2)
  }

  if (tipo == "intervalo") {
    a <- valor_app(input$a_region_app, quantile(x, 0.35))
    b <- valor_app(input$b_region_app, quantile(x, 0.65))
    inferior <- min(a, b)
    superior <- max(a, b)
    prob_teo <- acumulada(superior) - acumulada(inferior)
    prob_sim <- mean(muestra >= inferior & muestra <= superior)
    etiqueta <- paste0("P(", round(inferior, 3), " <= X <= ", round(superior, 3), ")")
  } else if (tipo == "derecha") {
    inferior <- valor_app(input$x_region_app, median(x))
    superior <- Inf
    prob_teo <- 1 - acumulada(inferior)
    prob_sim <- mean(muestra >= inferior)
    etiqueta <- paste0("P(X >= ", round(inferior, 3), ")")
  } else {
    inferior <- -Inf
    superior <- valor_app(input$x_region_app, median(x))
    prob_teo <- acumulada(superior)
    prob_sim <- mean(muestra <= superior)
    etiqueta <- paste0("P(X <= ", round(superior, 3), ")")
  }

  curva <- data.frame(x = x, y = y)
  sombra <- subset(curva, x >= inferior & x <= superior)

  list(
    modelo = nombre,
    parametros = parametros,
    muestra = muestra,
    curva = curva,
    sombra = sombra,
    prob_teo = prob_teo,
    prob_sim = prob_sim,
    media_teo = media_teo,
    sd_teo = sd_teo,
    etiqueta = etiqueta
  )
})

datos_tlc_app <- reactive({
  req(valor_app(input$modelo_app, "normal") == "tlc")
  set.seed(semilla_app())

  dist <- valor_app(input$tlc_dist_app, "exponencial")
  n_muestra <- as.integer(valor_app(input$tlc_n_app, 30))
  reps <- as.integer(valor_app(input$tlc_reps_app, 3000))

  if (dist == "normal") {
    mu <- valor_app(input$tlc_mu_app, 10)
    sigma <- max(valor_app(input$tlc_sigma_app, 2), 0.01)
    generar <- function(n) rnorm(n, mean = mu, sd = sigma)
    media_teo <- mu
    sd_teo <- sigma
    nombre <- "Normal"
    parametros <- paste("mu =", round(mu, 4), "| sigma =", round(sigma, 4))
  } else if (dist == "uniforme") {
    a <- valor_app(input$tlc_a_app, 0)
    b <- valor_app(input$tlc_b_app, 10)
    limites <- sort(c(a, b))
    a <- limites[1]
    b <- limites[2]
    if (a == b) b <- a + 1
    generar <- function(n) runif(n, min = a, max = b)
    media_teo <- (a + b) / 2
    sd_teo <- (b - a) / sqrt(12)
    nombre <- "Uniforme"
    parametros <- paste("a =", round(a, 4), "| b =", round(b, 4))
  } else if (dist == "exponencial") {
    lambda <- max(valor_app(input$tlc_lambda_exp_app, 1.5), 0.01)
    generar <- function(n) rexp(n, rate = lambda)
    media_teo <- 1 / lambda
    sd_teo <- 1 / lambda
    nombre <- "Exponencial"
    parametros <- paste("lambda =", round(lambda, 4))
  } else if (dist == "binomial") {
    size <- max(1, round(valor_app(input$tlc_size_app, 10)))
    p <- clamp_app(valor_app(input$tlc_p_app, 0.35), 0.01, 0.99)
    generar <- function(n) rbinom(n, size = size, prob = p)
    media_teo <- size * p
    sd_teo <- sqrt(size * p * (1 - p))
    nombre <- "Binomial"
    parametros <- paste("ensayos =", size, "| p =", round(p, 4))
  } else if (dist == "poisson") {
    lambda <- max(valor_app(input$tlc_lambda_pois_app, 3.5), 0.01)
    generar <- function(n) rpois(n, lambda = lambda)
    media_teo <- lambda
    sd_teo <- sqrt(lambda)
    nombre <- "Poisson"
    parametros <- paste("lambda =", round(lambda, 4))
  } else {
    N <- max(10, round(valor_app(input$tlc_N_app, 1000)))
    K <- clamp_app(round(valor_app(input$tlc_K_app, 350)), 1, N - 1)
    m <- clamp_app(round(valor_app(input$tlc_m_app, 30)), 1, N)
    generar <- function(n) rhyper(n, m = K, n = N - K, k = m)
    p <- K / N
    media_teo <- m * p
    sd_teo <- sqrt(m * p * (1 - p) * ((N - m) / (N - 1)))
    nombre <- "Hipergeometrica"
    parametros <- paste("N =", N, "| K =", K, "| extracciones =", m)
  }

  poblacion <- generar(10000)
  medias <- replicate(reps, mean(generar(n_muestra)))

  list(
    distribucion = nombre,
    parametros = parametros,
    poblacion = poblacion,
    medias = medias,
    n_muestra = n_muestra,
    reps = reps,
    media_teo = media_teo,
    sd_teo = sd_teo,
    error_estandar = sd_teo / sqrt(n_muestra)
  )
})

# Distribución Normal

La distribución normal, también conocida como distribución gaussiana o campana de Gauss, es la distribución de probabilidad continua más importante en la estadística. Su importancia radica en que muchos fenómenos naturales, sociales y económicos siguen este patrón.

La distribución normal es una herramienta fundamental para modelar una inmensa variedad de fenómenos en las ciencias, la ingeniería y la economía. Su popularidad se debe a una propiedad matemática conocida como el Teorema del Límite Central, que establece que la suma o el promedio de un gran número de variables aleatorias independientes, sin importar su distribución original, tiende a seguir una distribución normal.

**Características clave**

La distribución normal es un tipo de distribución de probabilidad continua. Esto significa que la variable aleatoria puede tomar cualquier valor dentro de un rango determinado. Se representa por una curva simétrica en forma de campana, donde la mayor parte de los datos se agrupan alrededor del valor central.

**Forma de campana:** la distribución es simétrica alrededor de su media. El punto más alto de la campana corresponde a la media.

**Media, mediana y moda coincidentes:** en una distribución normal perfecta, estos tres valores son iguales y se encuentran en el centro de la curva.

**Asintótica al eje horizontal:** la curva se extiende indefinidamente en ambas direcciones, acercándose al eje x pero sin llegar a tocarlo.

**Regla empírica:** alrededor del 68% de los datos se encuentran dentro de una desviación estándar de la media $(\mu \pm \sigma)$, el 95% dentro de dos desviaciones estándar $(\mu \pm 2\sigma)$ y el 99.7% dentro de tres desviaciones estándar $(\mu \pm 3\sigma)$.

**Parámetros**

La distribución normal está completamente definida por dos parámetros:

**Media $(\mu)$:** indica la ubicación del centro de la curva y el valor más probable.

**Varianza $(\sigma^2)$ o desviación estándar $(\sigma)$:** mide la dispersión o variabilidad de los datos. Una desviación estándar grande produce una curva más ancha y aplanada, mientras que una desviación estándar pequeña produce una curva más estrecha y alta.

**Fórmulas**

La fórmula principal de la distribución normal es la función de densidad de probabilidad. Esta función no calcula la probabilidad de un punto exacto, sino la densidad de probabilidad en ese punto.

::: {.formula}
La función de densidad de una variable normal es:

$$
f(x)=\frac{1}{\sigma \sqrt{2\pi}}
e^{-\frac{1}{2}\left(\frac{x-\mu}{\sigma}\right)^2}
$$

Donde $x$ es el valor de la variable aleatoria, $\mu$ es la media, $\sigma$ es la desviación estándar, $e$ es el número de Euler y $\pi$ es la constante pi.

La estandarización se realiza con:

$$
Z=\frac{x-\mu}{\sigma}
$$

La puntuación $Z$ indica cuántas desviaciones estándar está un valor dado respecto a la media. Luego se usan tablas o software estadístico para encontrar las probabilidades correspondientes.
:::

# Distribución Ji Cuadrado

La distribución ji-cuadrado $\chi^2$ es una distribución de probabilidad continua definida para valores no negativos. Surge de la suma de los cuadrados de variables normales estándar independientes y depende de un parámetro llamado grados de libertad. Su media es igual a los grados de libertad, su varianza es el doble de los grados de libertad y su forma varía según dicho parámetro: es muy asimétrica para valores pequeños y se aproxima a una normal al crecer.

Esta distribución es fundamental en estadística porque se utiliza en pruebas de hipótesis, como bondad de ajuste e independencia en tablas de contingencia, en la construcción de intervalos de confianza para varianzas y en la base de otras distribuciones como la t de Student y la F de Fisher. En términos intuitivos, mide la dispersión total al sumar cuadrados de desviaciones de normales, por lo que resulta clave para analizar varianzas y asociaciones entre variables.

**Parámetros y características**

A diferencia de la distribución normal, la distribución ji-cuadrado no está definida por una media y una desviación estándar, sino por un único parámetro:

**Grados de libertad $(v)$:** determina la forma de la distribución. A medida que los grados de libertad aumentan, la forma se vuelve más simétrica y se aproxima a una distribución normal.

**Valores no negativos:** la variable ji-cuadrado solo puede tomar valores positivos, ya que se calcula a partir de una suma de cuadrados. Por lo tanto, su curva comienza en cero y se extiende hacia la derecha.

**Asimétrica a la derecha:** presenta una cola larga hacia la derecha, especialmente con pocos grados de libertad.

**Media y varianza:** la media de la distribución es $\mu = v$ y la varianza es $\sigma^2 = 2v$.

**Dominio:** $X \ge 0$.

**Usos principales en estadística**

La distribución $\chi^2$ es fundamental en estadística inferencial. Se usa en pruebas de bondad de ajuste para verificar si los datos observados se ajustan a una distribución teórica, en pruebas de independencia para evaluar si dos variables categóricas son independientes y en intervalos de confianza para la varianza poblacional cuando la población es normal.

::: {.formula}
La función de densidad puede escribirse como:

$$
f(x;k)=\frac{1}{2^{k/2}\Gamma(k/2)}x^{k/2-1}e^{-x/2}, \quad x>0
$$

Aquí $\Gamma(\cdot)$ representa la función gamma y $k$ es el número de grados de libertad.
:::

# Distribución T de Student

La **distribución t de Student** es una distribución de probabilidad continua que surge al estimar la media de una población normalmente distribuida cuando el tamaño de la muestra es pequeño y la varianza poblacional es desconocida. Fue introducida en 1908 por William Sealy Gosset bajo el seudónimo de *Student*.

Su forma es simétrica respecto al cero, similar a la normal estándar, pero con colas más pesadas; por esta razón asigna mayor probabilidad a valores extremos. Depende de los grados de libertad: a mayor número de grados de libertad, la distribución se aproxima cada vez más a la normal estándar $N(0,1)$.

**Principales características**

**Forma:** es simétrica respecto al cero y tiene forma de campana.

**Parámetro:** depende de los grados de libertad $v$.

**Media:** es 0 para $v > 1$.

**Varianza:** es $\frac{v}{v-2}$ para $v > 2$.

**Usos principales**

Se usa en pruebas de hipótesis sobre medias, en la construcción de intervalos de confianza para la media y para modelar incertidumbre en muestras pequeñas cuando la desviación estándar poblacional no se conoce.

::: {.formula}
Si $Z \sim N(0,1)$ y $V \sim \chi^2_v$ son independientes, entonces:

$$
T=\frac{Z}{\sqrt{V/v}}
$$

sigue una distribución t de Student con $v$ grados de libertad.

Su función de densidad es:

$$
f(t)=
\frac{\Gamma\left(\frac{v+1}{2}\right)}
{\sqrt{v\pi}\,\Gamma\left(\frac{v}{2}\right)}
\left(1+\frac{t^2}{v}\right)^{-\frac{v+1}{2}},
\quad -\infty<t<\infty
$$
:::

# Distribución F de Fisher

La **distribución F**, también conocida como **F de Fisher-Snedecor**, es una distribución de probabilidad continua que surge a partir de la razón entre dos variables aleatorias chi-cuadrado normalizadas por sus grados de libertad.

La distribución F solo toma valores positivos, es asimétrica a la derecha y se concentra cerca de 1 cuando los grados de libertad son grandes. Es especialmente importante en el análisis de varianza, en pruebas de hipótesis sobre varianzas y en regresión lineal, donde la prueba F permite evaluar la significancia global de un modelo.

**Propiedades principales**

**Soporte:** $F > 0$.

**Asimetría:** la curva de densidad es sesgada a la derecha, especialmente con pocos grados de libertad.

**Esperanza matemática:** $E(F)=\frac{v_2}{v_2-2}$ para $v_2 > 2$.

**Varianza:** $\operatorname{Var}(F)=\frac{2v_2^2(v_1+v_2-2)}{v_1(v_2-2)^2(v_2-4)}$ para $v_2 > 4$.

**Usos más comunes**

Se utiliza en análisis de varianza para contrastar si varias medias poblacionales son iguales, en pruebas para comparar varianzas de dos poblaciones y en modelos de regresión lineal para evaluar la significancia global.

::: {.formula}
Si $X \sim \chi^2_{v_1}$ y $Y \sim \chi^2_{v_2}$ son independientes:

$$
F=\frac{X/v_1}{Y/v_2}
$$

Una forma de escribir su función de densidad es:

$$
f(x;v_1,v_2)=
\frac{\Gamma\left(\frac{v_1+v_2}{2}\right)}
{\Gamma\left(\frac{v_1}{2}\right)\Gamma\left(\frac{v_2}{2}\right)}
\left(\frac{v_1}{v_2}\right)^{v_1/2}
x^{v_1/2-1}
\left(1+\frac{v_1}{v_2}x\right)^{-\frac{v_1+v_2}{2}},
\quad x>0
$$
:::

# Teorema del Límite Central

El **Teorema del Límite Central** (TLC) es uno de los conceptos más importantes en estadística. En términos simples, establece que la **distribución de la media de una muestra** se aproxima a una **distribución normal** a medida que el tamaño de la muestra aumenta, sin importar la forma de la distribución original de la población.

**Concepto y analogía**

Imagina que tienes una población con una distribución extraña, por ejemplo muy sesgada. Si tomas una sola muestra grande de esa población y calculas su media, esa media se comportará de manera más predecible. Si repites este proceso muchas veces, las medias de todas esas muestras formarán un histograma que se parecerá cada vez más a una curva de campana, es decir, a una distribución normal.

Una analogía popular es la de los dados. La distribución de probabilidad de un solo dado es uniforme, porque cada número tiene la misma probabilidad. Sin embargo, si lanzas muchos dados y sumas sus resultados, la distribución de esas sumas se aproxima a una campana, con los resultados centrales siendo mucho más probables que los extremos.

**Puntos clave del teorema**

1. **Forma de la distribución de muestreo:** la distribución de las medias de la muestra se vuelve aproximadamente normal, aunque la población original sea normal, sesgada, uniforme o tenga otra forma.

2. **Tamaño de la muestra:** la aproximación a la normalidad es más precisa a medida que el tamaño de la muestra aumenta. Generalmente, una muestra de $n \ge 30$ se considera suficiente para que la aproximación sea razonable.

3. **Relación con la media de la población:** la media de la distribución de muestreo de las medias es igual a la media de la población.

4. **Relación con la desviación estándar de la población:** la desviación estándar de la distribución de muestreo de las medias, llamada error estándar, es igual a la desviación estándar de la población dividida por la raíz cuadrada del tamaño de la muestra.

**Importancia**

El Teorema del Límite Central permite utilizar la distribución normal para hacer inferencias sobre la media de la población, incluso cuando no se conoce la distribución de la población original. Esto es la base para muchas pruebas estadísticas, intervalos de confianza y procedimientos de inferencia.

::: {.resumen}
Si la población tiene media $\mu$ y desviación estándar $\sigma$, entonces la media muestral cumple aproximadamente:

$$
\mu_{\bar{x}}=\mu,
\qquad
\sigma_{\bar{x}}=\frac{\sigma}{\sqrt{n}}
$$

Por tanto, cuando $n$ es suficientemente grande:

$$
Z=\frac{\bar{X}-\mu}{\sigma/\sqrt{n}}\approx N(0,1)
$$
:::

    acumulada <- function(z) pnorm(z, mean = mu, sd = sigma)
    media_teo <- mu
    sd_teo <- sigma
    nombre <- "Normal"
    parametros <- paste("mu =", round(mu, 4), "| sigma =", round(sigma, 4))

    gl <- max(1, round(valor_app(input$gl_chi_app, 5)))
    muestra <- rchisq(n_sim, df = gl)
    x <- seq(0, qchisq(0.999, df = gl), length.out = 900)
    y <- dchisq(x, df = gl)
    acumulada <- function(z) pchisq(z, df = gl)
    media_teo <- gl
    sd_teo <- sqrt(2 * gl)
    nombre <- "Ji-cuadrado"
    parametros <- paste("gl =", gl)
  } else if (modelo == "t") {
    gl <- max(1, round(valor_app(input$gl_t_app, 10)))
    muestra <- rt(n_sim, df = gl)
    x <- seq(qt(0.001, df = gl), qt(0.999, df = gl), length.out = 900)
    y <- dt(x, df = gl)
    acumulada <- function(z) pt(z, df = gl)
    media_teo <- if (gl > 1) 0 else NA_real_
    sd_teo <- if (gl > 2) sqrt(gl / (gl - 2)) else NA_real_
    nombre <- "t de Student"
    parametros <- paste("gl =", gl)
  } else {
    gl1 <- max(1, round(valor_app(input$gl1_f_app, 5)))
    gl2 <- max(1, round(valor_app(input$gl2_f_app, 10)))
    muestra <- rf(n_sim, df1 = gl1, df2 = gl2)
    x <- seq(0, qf(0.995, df1 = gl1, df2 = gl2), length.out = 900)
    y <- df(x, df1 = gl1, df2 = gl2)
    acumulada <- function(z) pf(z, df1 = gl1, df2 = gl2)
    media_teo <- if (gl2 > 2) gl2 / (gl2 - 2) else NA_real_
    sd_teo <- if (gl2 > 4) {
      sqrt((2 * gl2^2 * (gl1 + gl2 - 2)) / (gl1 * (gl2 - 2)^2 * (gl2 - 4)))
    } else {

    }

    parametros <- paste("gl1 =", gl1, "| gl2 =", gl2)

  list(

    prob_sim = prob_sim,
    media_teo = media_teo,
    sd_teo = sd_teo,
    etiqueta = etiqueta
